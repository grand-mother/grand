Data format reference
=====================

..
   Generated by docs/dev/make_data_format.py from the tree classes; do not
   edit.  To change a description, edit the string under the field in
   grand/dataio/event_trees.py or grand/dataio/run_trees.py.

Every field of every tree GRANDlib reads and writes, with its type, unit and
meaning.  Run-level trees hold what stays the same for a whole run, one entry
per run; event-level trees hold one entry per event.  :doc:`datamodel`
explains how the trees fit together and how to read them.

Each tree is stored in its own file, named after the tree type:
``shower_*.root`` for ``TShower``, ``run_*.root`` for ``TRun`` and so on.


Run-level trees
---------------

``TRun``
~~~~~~~~

What stays the same over a run: the site, the layout and the detection units.  File: ``run_*.root``; API: :class:`~grand.dataio.run_trees.TRun`.

.. list-table::
   :header-rows: 1
   :widths: 22 22 10 46

   * - Field
     - Type
     - Unit
     - Description
   * - ``run_number``
     - ``uint32``
     - --
     - Run number, which identifies the entry.
   * - ``run_mode``
     - ``uint32``
     - --
     - Run mode (calibration, test or physics). The values are not yet defined.
   * - ``first_event``
     - ``uint32``
     - --
     - Number of the run's first event.
   * - ``first_event_time``
     - ``uint32``
     - --
     - Time of the first event, in Unix seconds.
   * - ``last_event``
     - ``uint32``
     - --
     - Number of the run's last event.
   * - ``last_event_time``
     - ``uint32``
     - --
     - Time of the last event, in Unix seconds.
   * - ``data_source``
     - ``str``
     - --
     - Where the data come from: ``detector``, ``sim`` or ``other``.
   * - ``data_generator``
     - ``str``
     - --
     - Name of the program that produced the data.
   * - ``data_generator_version``
     - ``str``
     - --
     - Version of the program that produced the data.
   * - ``event_type``
     - ``uint32``
     - --
     - Trigger type: 0x1000 for the 10-second trigger, 0x8000 for a random trigger; any other value is a shower trigger.
   * - ``event_version``
     - ``uint32``
     - --
     - Version of the DAQ's event format.
   * - ``site``
     - ``str``
     - --
     - Name of the site, such as ``Dunhuang`` or ``Xiaodushan``.
   * - ``site_layout``
     - ``str``
     - --
     - Name of the antenna layout, such as ``GP300``.
   * - ``origin_geoid``
     - ``array of shape 3, float32``
     - --
     - Origin of the array frame: (latitude in degrees, longitude in degrees, height in meters). du_xyz is relative to it.
   * - ``du_id``
     - ``std::vector<int>``
     - --
     - Identifier of each detection unit.
   * - ``du_geoid``
     - ``std::vector<vector<float>>``
     - --
     - Detector unit (antenna) position: (latitude in degrees, longitude in degrees, height in meters) per DU.
   * - ``du_xyz``
     - ``std::vector<vector<float>>``
     - --
     - Position of each unit in the array frame, in meters: x north, y west and z up, relative to ``origin_geoid``.
   * - ``du_type``
     - ``std::vector<string>``
     - --
     - Antenna type of each unit.
   * - ``du_tilt``
     - ``std::vector<vector<float>>``
     - --
     - Tilt of each antenna, as two angles.
   * - ``du_ground_tilt``
     - ``std::vector<vector<float>>``
     - --
     - Tilt of the ground at each antenna, as two angles.
   * - ``du_nut``
     - ``std::vector<int>``
     - --
     - Identifier of each unit's nut, the antenna head that holds the low-noise amplifier.
   * - ``du_feb``
     - ``std::vector<int>``
     - --
     - Identifier of each unit's front-end board.
   * - ``t_bin_size``
     - ``std::vector<float>``
     - ns
     - Sampling interval of each unit's traces, in ns: the inverse of the sampling frequency.

~~~~~~~~~~~~~~~~~

Simulation settings of the electric-field traces, common to all events of a run.  File: ``runefieldsim_*.root``; API: :class:`~grand.dataio.run_trees.TRunEfieldSim`.

.. list-table::
   :header-rows: 1
   :widths: 22 22 10 46

   * - Field
     - Type
     - Unit
     - Description
   * - ``run_number``
     - ``uint32``
     - --
     - Run number, which identifies the entry.
   * - ``refractivity_model``
     - ``str``
     - --
     - Name of the atmospheric index of refraction model.
   * - ``refractivity_model_parameters``

     - ``float32``
     - --

   * - ``site``
     - ``str``

     - Site for which the efield simulation was done.
   * - ``sim_name``
     - ``str``
     - --
     - Simulator name (aires/corsika, etc.)
   * - ``sim_version``
     - ``str``
     - --
